# 规则 02：线上服务器与软路由“零断网、防锁死”操作铁律

当任务涉及连接用户的软路由网关（如 OpenWrt）或线上生产 VPS 时，必须把**不断网、不失联**作为最高优先级前提。

## 1. 软路由网关（透明代理）零断网准则

- **严禁先停代理再拉配置**：软路由往往是开发机自身的上网出口。**绝对禁止**在未生成并校验好新配置前执行 `sing-box stop` 或删除防火墙表，否则会导致无法拉取外部订阅/规则集并造成局域网断网。
- **两阶段原子切换流程**：
  1. **只读备份**：修改前先以 `0600` 权限备份现有二进制、`singctl.yaml` 与 `/etc/sing-box/config.json`。
  2. **离线预生成与语法校验**：在 `/tmp` 预生成新配置，执行 `sing-box check -c /tmp/...` 确认返回 `0` 且包含非空代理出站节点。
  3. **原子替换 + 自动回滚兜底**：使用 `mv` 原子替换配置并重载；远程脚本内必须自带出站连通性探测与失败自动回滚逻辑，同时将后台守护进程的输入输出重定向脱离 SSH 管道（`</dev/null >/tmp/... 2>&1`），防止卡死会话。
- **POSIX / BusyBox 兼容**：在 OpenWrt（`ash` + BusyBox）上禁止盲目使用 GNU 专属参数，优先使用标准 POSIX 语法。

## 2. 远端 VPS SSH 端口与防火墙防锁死准则

- **双端口过渡验证**：任何修改 SSH 端口（如 `22 -> 2222`）或禁用密码登录的操作，必须先放行防火墙目标端口并让 `sshd` 同时监听新旧双端口，经 `sshd -t` 校验重载后，**从外部真实使用密钥连入新端口验证成功**，方可关闭旧端口与密码登录；一旦外部验证失败必须自动回滚。
- **双公钥保护**：在新机禁用密码登录前，必须确保同时保留或注入操作者本机公钥与主控管理公钥，防止把用户个人电脑锁在门外。
