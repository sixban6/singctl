# 广域网主动探测模拟与抗压风险评估 (Active Probing & Threat Benchmark)

命令前缀：`singctl gfw` / `singctl probe` / `singctl detect`

模拟网络边界扫描与主动探测 (Active Probing) 手段，对指定 IP 进行多维度探测与特征画像分析，给出 0~100 分量化风险评分（分值越低越安全，越高说明暴露了非标准网关特征），并输出精准的节点服务加固建议。

---

## 背景与原理

现代传输协议（如 VLESS Reality、Hysteria 2、Trojan、Shadowsocks）在处理高并发流量时，外部扫描与主动探测集群会针对目标主机发起主动探测，检验服务端的行为是否符合标准 Web 协议栈规范。

主动探测常用的识别手段包括：
1. **注入高熵未知数据**：发送 64 字节伪造加密密文，观测服务端是否处于长期挂起等待客户端认证状态（标准 Web 服务器通常会快速 RST 或返回 HTTP 400）；
2. **随机伪造 SNI 握手**：发送随机未知域名，检验服务端是否泄露非预期的目标证书；
3. **Reality 偷取时延梯级差 (RTT)**：比对 TCP 握手时延与 TLS 握手时延的比率，评估是否存在跨地域远程中继特征；
4. **Reality 强制 TLS 1.2 降级**：检验服务端对不同版本 ClientHello 的回落响应是否一致连贯；
5. **ALPN 虚标与 HTTP/2 协议栈**：检验外层声明 `h2` 后，底层是否能正确处理 HTTP/2 Preface 与 SETTINGS 帧交互；
6. **协议特征路径分流探测**：对常见路径（如 `/ws`）发送 Upgrade 探针，与基准随机路径对照检测分流差异；
7. **QUIC 版本协商与 RFC 9000 规范**：针对 UDP 443 发送特殊保留版本报文测试版本协商行为。

---

## 风险评分模型

评估系统将各大维度的特征扣分进行累加，评分范围为 **0 ~ 100 分**：

| 分数区间 | 风险级别 | 状态说明 |
| :--- | :--- | :--- |
| **0 ~ 20 分** | `Clean (正常/安全)` | 未发现异常私有协议特征，行为与标准公网 Web 服务器高度一致 |
| **21 ~ 50 分** | `Low (低风险/轻度存疑)` | 存在个别未对齐规范的非标准响应或时延抖动，建议按提示微调 |
| **51 ~ 75 分** | `High (高风险/高度存疑)` | 暴露了明显的回落差异、路径分流特征或握手异常，容易被异常标记 |
| **76 ~ 100 分** | `Critical (极度危险/特征显著)` | 直接暴露了高熵挂起等待认证、敏感管理端口泄露或非标协议特征 |

## 五大检测维度详解

```
singctl gfw
  ├── [1/5] 基础端口与服务画像探测 (15 分)
  ├── [2/5] HTTP 规范与回落伪装测试 (25 分)
  ├── [3/5] TLS 与 Reality 伪装主动探测 (35 分)
  ├── [4/5] 高熵随机垃圾数据探测 (20 分)
  └── [5/5] UDP / QUIC (Hysteria2) 协议探测 (15 分)
```

> **性能保障**：以上 5 大维度采用 **并发协程** 执行，无论单项是否超时，全套测试通常在 **1 ~ 3 秒** 内即可快速完成。

### 1. 基础端口与服务画像探测 (满分 15 分)

- **80/443 端口对称性分析**：商业 Web 站点几乎 100% 开放 80 端口用于 ACME 证书挑战与 HTTP 跳转。若 443 开放而 80 关闭/超时，将增加风险分。
- **HTTP 到 HTTPS 重定向合规度**：检验 80 端口是否返回规范的 301/302/307/308 重定向到 HTTPS。
- **敏感管理端口暴露扫描**：扫描常见内部管理端口（`7895`、`9090`、`9091`、`2080`、`1080`）。
  - *内置金丝雀防误报*：扫描前自动探测高位随机端口 `59183`，若客户端处于全端口转发环境中，自动判定为假阳性并跳过，避免误报。

### 2. HTTP 规范与回落伪装测试 (满分 25 分)

- **裸 IP 访问与伪装页面真实性**：直接以 IP 访问 443/80 端口（遵循 RFC 6066 规范不发送 SNI 扩展），检验是否返回合规的静态网页，识别是否泄露后端特征关键词或返回空白 200。
- **畸形 HTTP 报文容错合规性**：发送缺少冒号的非法报文头部，检验服务端是否返回标准 RFC 7230 400 Bad Request。
- **特征路径分流探测**：向常见路径发送 WebSocket Upgrade 探针，并与随机基准路径（如 `/rnd-probe-xxxx`）对照。若特征路径返回 101 Switching Protocols 或出现异常状态码差异，则判定存在分流暴露。

### 3. TLS 与 Reality 伪装主动探测 (满分 35 分)

- **随机伪造 SNI 握手与证书泄露探测**：使用随机伪造域名发送 TLS ClientHello，检验服务端是正确发送 TLS Alert (unrecognized_name)，还是直接断开，或错误泄露了证书域名。
- **目标 SNI 伪装度与网络 RTT 梯级时延分析**：测量 TCP 握手时延与 TLS 握手时延，结合协商版本的比率模型，评估是否存在跨地域中继时延偏差。
- **Reality TLS 1.2 强制降级探测**：强制客户端仅提供 TLS 1.2 发起握手，检验服务端回落至真实目标站点的连贯性。
- **ALPN 协商与 HTTP/2 协议栈一致性**：同时声明 `h2` 与 `http/1.1`。若协商为 `h2`，验证服务端底层是否原生支持 HTTP/2，识别外层伪装与后端协议错配。
- **TLS Alert RFC 规范性**：发送非法记录层报文，检验是否回复标准格式的 TLS Alert（Type: 0x15，含正确的 Level 与 Description 字段）。

### 4. 高熵随机垃圾数据探测 (满分 20 分)

- **高熵未知随机数据包注入测试**：模拟外部扫描器发送 64 字节高随机度数据，高精度测量服务端断开连接的耗时：
  - 若服务端挂起等待超过 2 秒甚至超时，判定为“服务端异常挂起等待握手认证”的非标 Web 行为；
  - 若在 1 秒内快速 RST / FIN 拒绝或返回 HTTP 400，表现符合现代标准 Web 协议栈规范。

### 5. UDP / QUIC (Hysteria2) 协议探测 (满分 15 分)

- **畸形 QUIC 数据包与版本协商探测**：向 UDP 443 发送填充满 1200 字节（RFC 9000 防放大规范）且携带保留版本号（`0x1a2a3a4a`）的 Initial 包。若目标未开启 UDP 则安全通过不扣分；若响应则校验是否符合标准 QUIC Version Negotiation 格式。
- **UDP 随机高熵数据吞吐测试**：向 UDP 443 发送随机数据包，检验是否遵循防御反射放大 DDoS 的静默丢弃规范。

## 命令详解与参数说明

```bash
# 探测指定 IP（默认单项超时 4 秒，检测 80 与 443 端口）
singctl gfw 1.2.3.4

# 指定节点所属域名与伪装 SNI 进行深度比对（强烈推荐）
singctl gfw 1.2.3.4 --domain cdn.example.com --sni swdist.apple.com

# 指定自定义端口进行探测（支持单端口或逗号分隔的多端口）
singctl gfw 1.2.3.4 -p 8443
singctl gfw 1.2.3.4 -p 8080,8443

# 显示详细探测过程与底层协议栈交互日志
singctl gfw 1.2.3.4 -v

# 以 JSON 格式输出检测报告（适合集成至自动化 CI / 监控面板）
singctl gfw 1.2.3.4 --json
```

| 参数 | 缩写 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `--ports` | `-p` | `80,443` | 自定义探测端口列表（如 `-p 8443` 或 `-p 80,443`） |
| `--sni` | | `""` | Reality / 伪装 SNI 域名（例如 `swdist.apple.com`） |
| `--domain` | | `""` | 节点所属真实业务域名（例如 `cdn.l1.example.com`） |
| `--timeout` | `-t` | `4` | 单项探测超时时间（秒） |
| `--verbose` | `-v` | `false` | 显示详细的探测过程与调试详情 |
| `--json` | | `false` | 以结构化 JSON 格式输出检测报告 |
